# 经验交接采用固定版本导入

2026-11-04 使用者确认：新 Bot 导入获授权的固定版本经验与 Skill，之后独立积累，不持续跟随源 Bot 或源 Skill 更新。这样源业务的后续变化不会自动改变目标业务的工作方式，代价是需要复用新经验时重新选择并接纳一个新版本。

经验交接包只包含选定且获准交接的记忆、经验、Skill 及其来源、适用条件和已知局限，不默认迁移整个聊天或原始业务资料。原包保持不变，目标 Bot 使用独立副本继续整理和纠错；后续源更新形成新包，由目标侧明确接纳，不能自动覆盖目标已积累的内容。源 Bot 停止原业务不触发已授权交接内容的自动删除，原始交易证据仍归属原业务。

经验导入不继承凭据、角色权限、算法启用批准、交易批准或额度；目标 Bot 继续受自身工作区及模板权限约束。改变交易计算的内容仍须经过算法或规则版本的验证与批准。跨工作区交接须满足所选内容的导出及目标使用授权，遵守 [ADR 0004](0004-trading-general-workspace-isolation.md)，不能借经验包修改来源交易工作区。

**状态：架构已确认，完整经验交接待实施。** 现有记忆、Skill、Agent 导入及经验文字共享可作为基础，不表示已经具备上述业务交接闭环。实施时须定义包版本与内容校验、来源追溯、导入记录、目标副本、更新冲突，以及授权撤销后的保留与使用规则。
