# 经验交接采用固定版本导入

2026-11-04 使用者确认：新 Bot 导入获授权的固定版本经验与 Skill，之后独立积累，不持续跟随源 Bot 或源 Skill 更新。这样源业务的后续变化不会自动改变目标业务的工作方式，代价是需要复用新经验时重新选择并接纳一个新版本。

经验交接包只包含选定且获准交接的记忆、经验、Skill 及其来源、适用条件和已知局限，不默认迁移整个聊天或原始业务资料。原包保持不变，目标 Bot 使用独立副本继续整理和纠错；后续源更新形成新包，由目标侧明确接纳，不能自动覆盖目标已积累的内容。源 Bot 停止原业务不触发已授权交接内容的自动删除，原始交易证据仍归属原业务。

经验导入不继承凭据、角色权限、算法启用批准、交易批准或额度；目标 Bot 继续受自身工作区及模板权限约束。改变交易计算的内容仍须经过算法或规则版本的验证与批准。跨工作区交接须满足所选内容的导出及目标使用授权，遵守 [ADR 0004](0004-trading-general-workspace-isolation.md)，不能借经验包修改来源交易工作区。

**状态：2026-11-05 固定版本交接 MVP 后端与 Web 已实施。** 已提供选择性快照、版本链与哈希、源/目标所有权校验、预览和原子确认、独立副本、显式冲突处理、幂等重试及历史保留。Skill 默认待启用，用户启用不授予交易或算法权限；撤销阻止新导入，已合法导入的独立副本保留。当前限同用户、原生记忆与文本 Skill，外部记忆安全拒绝。实现、隔离数据库验证和未验收边界见[交接 MVP 后端记录](../implementation/eTraderBot-experience-handoff.md)，接口见[前端接入说明](../integration/eTraderBot-experience-handoff-api.md)。

Web/Electron 共用选择、预览、确认与历史页面；来源标签、过期预览恢复及错误语言切换已有定向浏览器回归。源区权限撤销、凭据/交易授权不转移及相同 confirm 幂等通过的是隔离 RPC/PostgreSQL 测试，浏览器 HTTP 重试仍未验证。移动端暂无入口，原生设备和模型效果提升未验收，详见[前端记录](../implementation/eTraderBot-experience-handoff-frontend.md)。
